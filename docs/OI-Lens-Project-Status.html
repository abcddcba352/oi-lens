1. Project అంటే ఏమిటి?

OI Lens అనేది NSE F&O stocks మరియు indices కోసం Open Interest (OI), OI change, option volume, price history మరియు పాత wall outcomes ఉపయోగించి support/resistance zones చూపించే local web app.

ఇది guaranteed trading signal కాదు. ఇది data-based decision-support tool. ప్రతి stock తన సొంత historical data నుంచే నేర్చుకోవాలి; ఒక stock data‌ను ఇంకొక stock‌కు కలపకూడదు అనే rule అమలులో ఉంది.

2. Project ప్రస్తుతం ఏమి చేస్తుంది?

  • FYERS login ద్వారా live option chain మరియు six-month price history తీసుకుంటుంది.
  • Pure OI wall కాకుండా OI cluster, fresh OI/unwinding, volume, spot distance, persistence, volatility regimeలను కలిపి rank చేస్తుంది.
  • Intraday మరియు positional/longer-term support-resistanceలను విడిగా చూపిస్తుంది.
  • Support/resistanceను exact point‌గా కాకుండా zone, invalidation level మరియు confidence/strengthతో చూపిస్తుంది.
  • పాత predictionను తరువాతి price candlesతో test చేసి “reached, held, bounced, broke” outcomesగా save చేయగలదు.
  • Stock model index model కంటే వేరే liquidity filters, ATR width మరియు weighting ఉపయోగిస్తుంది.

5. Support/Resistance learning flow

  1. ఆ రోజు nearest-expiry option chain నుంచి major put OI clusters = support candidates; major call OI clusters = resistance candidates.
  2. Zero-volume/isolated strikes filter అవుతాయి. OI change మరియు traded volume wall నిజంగా activeగా ఉందా అని confirm చేస్తాయి.
  3. Spot distance, ATR volatility మరియు neighbouring strike cluster strengthతో candidate score వస్తుంది.
  4. Prediction date, strike, side మరియు features D1లో save అవుతాయి.
  5. తర్వాతి trading sessionsలో price ఆ wallని touch చేసిందా, hold/bounce అయిందా లేదా break అయిందా test అవుతుంది.
  6. కనీస sample count వచ్చిన తర్వాత అదే stock historical hold-rate/model calibration కొత్త levels rankingను adjust చేస్తుంది.

9. Risks and safeguards

  • OI wall can move or disappear; therefore it is not a fixed guarantee.
  • Historical performance must be shown only from out-of-sample future candles, never using future data during declaration.
  • Different expiries must not be treated as one continuous contract.
  • Illiquid strikes and zero-volume OI need filtering, especially for stocks.
  • App ID, Secret ID, auth code and access token must never be placed in reports or source control.
